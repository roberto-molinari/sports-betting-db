## Features
* core model - supports two pipelines for generating team lambdas to feed into poisson modeling.  
** player-level pipeline: uses player level xG as the foundation, and windowing to inform player-based team lambdas.  
** team-level pipeline: uses a blend of team level actual goals and team level xG, along with windowing to inform team-based team lambdas. The team level xG is also stretched to give distributions that better reflect reality. Note that the shipped default is pure xG as of this writing
The two pipelines are blended together by a trust score (roster continuity + minutes coverage), each matchday to generate an attack and defense lambda for the team. When computing player level stats, the model is season and league agnostic (i.e. looks back N matches, regardless of whether or not those prior matches for the player happened in the current season or team).  To that point, we have Serie B data for players that have been promoted (either individually or as a team)
* markets - the model supports 1x2 and over/under (single total per match only)
* bet selection - the model has a probability floor (0.25) that filters out noisy longshot picks before staking. 
* card generation - a script, generate_club_league_card.py, runs this model and generates picks for the given matchday / league.  This new script replaces the older generate_serie_a_card.py
* data sources: Betfair Exchange is the sharp book source and Bet365 is the soft book source

## Feature Backlog
See BUGS.md for complete list and details, these are the largest/most likely next candidates for work
* More leagues - add support for major European leagues (Premier, Bundesliga, La Liga, etc)
* New market types - more totals lines — BTTS, Asian handicap, correct score, etc. 
* Performance - BUG-011 (redundant SQL during backfills) — pure performance, but directly relevant to "add more leagues" since slow backfills get more painful as leagues multiply.
* Pick/probability lineage (FEATURE-012) and FEATURE-013 (fatigue/coaching/weather factors) — both already scoped and logged in BUGS.md.
* Line shopping / multi-book staking — ROI is currently computed against one fixed book (Bet365) as if that's the only place to bet.
* Bankroll/stake sizing - implement Kelly criterion or confidence-weighted staking.
