Match day experience (or matchday-1 experience)

* one script to generate picks for matches in the league supports
* each pick must include home team, away team, the pick (i.e. home/away/draw or over/under with a total), along with the model's expected probability, the EV (against the soft books implied probability)
* the system must remember the details of the pick to enable later scoring (see post match day experience for details on report)
* each leagues pick's for the day must be "post friendly" so it can be copy/pasted into a tweet

Post match day experience
* generate a scorecard for the prior days league performance (ROI and right/wrong) per league
* generaet a scorecard for the prior days overall perforance (ROI and right/wrong across leagues)
* be able to generate a trend graph per league/market/season/overall over the past N days/weeks/months on model performance for ROI, as well as performance against sharp and soft books (can take any # of days, weeks or months to go back)
